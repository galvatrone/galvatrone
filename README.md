### `> whoami`

I'm a Computer Science student and software developer based in Cyprus. I enjoy working close to the system — from C++ memory management and network protocols to computer vision, offline AI, and robotics.

- **Focus:** C++, Rust, Python, Linux, AI/ML, networking, and automation
- **Current interests:** autonomous AI assistants, cross-platform systems, reliable communications, and robotics
- **Engineering approach:** understand the internals, build working prototypes, measure behavior, then improve reliability
- **Open to:** software engineering, systems programming, and AI/ML internship opportunities across the EU
